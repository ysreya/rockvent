Bulk import

Import dozens of products in one step using CSV. Existing products with the same code are updated; other products are added. To include photographs, use an HTTPS image URL in the CSV, or edit each product to upload its photograph.

How to use

1. Add product name, code and category.
2. Upload a photo or paste image URL.
3. Click Save. The live catalog updates immediately.

Important: Configure a persistent Railway volume mounted at /app/data to retain uploads and product edits after deployments.
